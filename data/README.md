# Data

| File | Role |
| --- | --- |
| `all_blocks.csv` | Main-chain and locally observed orphan blocks |
| `raw_jobs.csv` | Qubic pool job notifications |
| `blocks-proof.csv` | Community-shared Qubic block evidence |
| `selfish_mining_blocks.csv` | Run summary generated by `plot_orphan_run_length.py` |

The analysis treats hashes in `blocks-proof.csv` as additional positive Qubic labels and adds proof-only orphan blocks that fall inside the node observation window. Existing node-derived Qubic labels are retained because the community dataset is not assumed to be complete. Duplicate records are matched by block hash, and `is_proofed` records proof-dataset provenance.
